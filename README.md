# Yatin Patil - Developer Portfolio

A modern, fast, and minimalistic personal portfolio built using Next.js 15, React, Tailwind CSS v4, and Framer Motion.

## Features
- **Next.js App Router**: Fast routing and server components.
- **Tailwind CSS v4**: Utility-first styling with sleek theming.
- **Dark Mode**: Integrated using `next-themes`.
- **Responsive & Minimal**: Clean UI focusing on content.
- **SEO Optimized**: Pre-configured meta tags.

## Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment to Vercel

The easiest way to deploy this Next.js app is to use the Vercel Platform.

**Via Vercel Git Integration:**
1. Push this code to a new repository on GitHub.
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **Add New** > **Project** and select your GitHub repository.
4. Click **Deploy**. Vercel will automatically detect Next.js and build it.

**Via Vercel CLI:**
1. Install globally: `npm i -g vercel`
2. Run `vercel` in the project directory and follow the prompts.
